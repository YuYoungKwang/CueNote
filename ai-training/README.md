# CueNote OMR Training Skeleton

This directory is a Phase 8 scaffold for Phase 9 dataset and model development. It does not contain a trained product OMR model, checkpoints, or accuracy claims.

Phase 9 will fill in:

- dataset manifests and source-level train/validation/test splits
- layout and symbol label schemas
- training, evaluation, ONNX export, and ONNX validation scripts
- browser compatibility and performance reports

The browser app currently uses only `TEST_RUNTIME_MODEL` to verify ONNX Runtime Web infrastructure.
